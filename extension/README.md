# GeoScr — розширення Chrome для локатора (без ШІ)

Власне розширення (Manifest V3, без Tampermonkey), яке показує HUD математичного локатора просто у вікні
GeoGuessr: найімовірніші країни з імовірностями, регіони, що видно на панорамі, картки-підказки GeoGuessr
і Plonk It з картинками, «куди дивитися» й знайдений напрямок, точку здогадки з очікуваними балами, час
аналізу. Аналіз робить локальний сервер `web/server.py` (у WSL); розширення лише знімає те, що бачить
гравець, і показує відповідь.

## Встановлення

1. Запустіть сервер у WSL (з кореня проєкту):

   ```bash
   python3 web/server.py            # http://localhost:8080
   ```

   WSL2 сам пересилає `localhost` у Windows, тож Chrome на Windows бачить сервер за тією самою адресою.
   Перевірка з Windows: відкрийте `http://localhost:8080/api/health` — має бути `{"ok": true, ...}`.

2. Один раз (і після оновлення бази підказок) завантажте картинки карток у локальний кеш — між іграми,
   не під час раунду:

   ```bash
   python3 tools/fetch_hud_images.py      # ~900 картинок, ~20 МБ у scratch/hud_img/, ~20 хв (запит раз на 1,3 с)
   ```

   HUD ніколи не вантажить картинки з www.geoguessr.com: їх бере розширення з цього кешу через локальний
   сервер. Без кешу картки показуються без картинок.

3. Відкрийте в Chrome `chrome://extensions`, увімкніть **Режим розробника** (Developer mode, перемикач
   праворуч угорі).

4. Натисніть **Завантажити розпаковане** (Load unpacked) і виберіть теку `extension` проєкту:

   ```
   \\wsl.localhost\Ubuntu-20.04\home\yurka\projects\geoscr\extension
   ```

   Якщо Chrome не відкриває мережевий шлях WSL, скопіюйте теку на диск Windows і завантажте копію:

   ```bash
   cp -r extension /mnt/c/Users/yurka/geoscr-extension     # у Chrome: C:\Users\yurka\geoscr-extension
   ```

   HUD (`hud/hud.js`, `hud/hud.css`) входить до розширення, сервер код не надсилає. Після `git pull`
   натисніть ⟳ на картці розширення в `chrome://extensions` (копію на диску C: спершу оновіть тією ж
   командою `cp -r`) і перезавантажте сторінку гри (F5).

5. Налаштування: клік по значку розширення (або «Деталі → Параметри розширення»). Там адреса сервера
   (типово `http://localhost:8080`; дозволено лише цей комп’ютер або локальну мережу), кнопка
   «Перевірити з’єднання», автоаналіз на початку раунду та режим перевірки на повторах завершених ігор.

## Використання

Грайте як завжди на `https://www.geoguessr.com`. На одиночних сторінках `/game/<токен>` і
`/challenge/<токен>` з’являється HUD (зазвичай ліворуч, під логотипом; він обходить карту здогадки навіть
у найбільшому розмірі, панель статусу, таймер, компас і кнопки зуму, а на малих вікнах стає праворуч від
кнопок).

| Клавіші | Дія |
|---|---|
| `Alt+G` | аналізувати поточну панораму (або кнопка «Аналіз») |
| `Alt+H` | сховати / показати HUD (схований HUD — кружок «Л») |
| `Alt+1` … `Alt+3` | підказки країни 1–3 |
| `Alt+A` | автоаналіз на початку кожного раунду й після кожного переходу (ігри з рухом) |
| `Alt+C` | згорнути / розгорнути |

Клавіші працюють за фізичною позицією, тож і з українською розкладкою. HUD можна перетягнути за
заголовок, місце запам’ятовується; подвійний клік по заголовку повертає автоматичне розміщення. На
малих вікнах (менше ≈1280×740) HUD компактний: спершу регіони й картки вибраної країни (знайдені на
панорамі — першими), описи карток розгортаються кліком по назві.

Під час аналізу камера кілька секунд оглядає панораму (2 ряди по 4–5 кадрів), потім повертається в
початкове положення; кадри читаються прямо з canvas Street View. У раундах без обертання знімається один
поточний кадр, у раундах без зуму зум гравця не змінюється. Кнопка «Показати» біля знайденої картки
повертає камеру в напрямку, де її знайдено; вона є лише тоді, коли відомо, що гра дозволяє обертання.

Автоаналіз типово вимкнений. GeoGuessr записує рухи камери в повтор і звичайних ігор (`/game/…`), і
челенджів, тож швидкий огляд панорами видно в повторі будь-якої гри, де був аналіз.

**Ігри з рухом.** З увімкненим «Авто» кожен перехід на іншу панораму раунду аналізується, щойно ви
зупинитесь (1,5 с без переходу, повороту камери й натискань; поки панорама затиснута мишею, нічого не
знімається). Будь-яке натискання під час огляду (панорама, карта, HUD) чи клавіша руху / повороту одразу
зупиняє огляд і ще в цьому ж натисканні повертає вашу камеру (напрямок, нахил, зум), тож перетягування
починається з вашого вигляду; огляд повториться після наступної зупинки. Сервер зливає всі панорами
раунду в одну відповідь (країни, регіони, точка, підказки); HUD пише, скільки панорам у відповіді, чи
остання змінила відповідь, і найімовірнішу країну кожної панорами окремо. Повторний знімок тієї ж панорами
(повернення на старт) замінює попередній, новий раунд починається з нуля. **Без «Авто» підказки після
переходу самі не оновлюються:** HUD пише «Ви перемістились…», і `Alt+G` додає нову панораму. Сервер знає
раунд лише за типом гри, токеном і номером раунду; поки номер раунду невідомий, панорами не зливаються.

## Чесна гра

- Працює лише в одиночних іграх: `/challenge/<токен>` і `/game/<токен>` з типом гри standard або
  challenge. На дуелях, Battle Royale, Play-Along, вечірках, у меню розширення нічого не показує, нічого
  не знімає й не автоматизує.
- Розширення не робить жодного запиту до GeoGuessr: ні до API, ні по картинки карток, і не читає
  локацію раунду (ні id панорами, ні координат). З відповідей, які сторінка отримує сама, береться тільки
  білий список налаштувань (карта, межі карти, ліміт часу, заборони руху / зуму / обертання, номер
  раунду).
- Здогадку розширення ніколи не ставить — точку на карті ставите ви.
- Що може помітити сама сторінка GeoGuessr: перехоплення StreetViewPanorama / WebGL / fetch мусять бути
  на кожній сторінці (сайт не перезавантажується між меню й грою). Усе інше лише на одиночних сторінках:
  вузол HUD і ключ `geoscr-hud` (місце й стан HUD) у localStorage. Глобальних змінних немає, зв’язок зі
  службовою частиною розширення йде приватним каналом (MessagePort), сторінка його не бачить. Ключ
  `__geoscr_cfg` у localStorage з’являється лише в режимі перевірки на повторах.

## Перевірка на повторі завершеної гри

Увімкніть у налаштуваннях «Режим перевірки на повторах», відкрийте повтор своєї **завершеної** гри
`https://www.geoguessr.com/game/<токен>/replay?round=1` і натисніть `Alt+G`. З WSL те саме автоматично
(розширення в окремому Chrome, сервер на порту 8094):

```bash
python3 web/server.py --port 8094 &
LOCATOR_URL=http://localhost:8094 node play_live_visual.js --replay <токен завершеної гри> --round 2 --extension
LOCATOR_URL=http://localhost:8094 node play_live_visual.js --replay <токен> --round 3 --extension --moves 3 --interrupt hud   # рух: 3 кроки прогулянки (кеш tools/moving_calib.py), клік по HUD під час огляду
python3 tools/rebuild_views.py scratch/live/<токен>_r2     # реєстрація кадрів: s = 1.000, якщо поле зору виміряне правильно
```

## Файли

```
manifest.json   MV3: hud/hud.js + page.js у світі сторінки на document_start, content.js, service worker
page.js         спільний із play_live_visual.js код сторінки: перехоплення StreetViewPanorama, вимір поля
                зору (матриця WebGL або формула tan(hfov/2) = 2^(1-zoom)), знімання canvas
                (preserveDrawingBuffer або читання одразу після кадру), керування раундом і HUD
hud/            копія web/hud/hud.js і hud.css (той самий HUD, що й у play_live_visual.js)
content.js      приватний канал сторінка ↔ service worker, налаштування
background.js   єдине місце, що звертається до сервера локатора (/api/predict, /api/health, /hud/img)
options.*       сторінка налаштувань
```

Після змін у `web/hud/` оновіть копію: `cp web/hud/hud.js web/hud/hud.css extension/hud/` (тест
`node --test play_live_visual.test.js` перевіряє, що копія збігається).

Якщо HUD не з’являється: перевірте, що це одиночна гра, що сервер запущений
(`http://localhost:8080/api/health`), що адреса в налаштуваннях правильна, і перезавантажте сторінку гри
(F5). Після оновлення розширення (⟳ у `chrome://extensions`) відкриті сторінки GeoGuessr теж треба
перезавантажити.

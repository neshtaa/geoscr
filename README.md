# 🌍 GeoGuessr Vision Locator & Plonk It Intelligence Engine

Проєкт для надшвидкого та точного визначення місцезнаходження (країни та її регіону) за фотографіями чи панорамами Street View/GeoGuessr за лічені секунди, використовуючи структуровану базу знань **Plonk It**, офіційну базу **післяматчевих підказок GeoGuessr**, та модулі комп'ютерного зору.

---

## 📌 Можливості проєкту

1. **Повна об'єднана база знань Plonk It (136 країн) та GeoGuessr Learning Hub**:
   - `data/plonkit_kb.json` (4.78 MB): 136 країн та територій з детальними інструкціями по регіонах.
   - `data/country_rules.json`: структуровані правила сторін руху, ліній, номерних знаків та камер.
   - `data/geoguessr_kb.json`: 114 профілів країн з офіційного Learning Hub GeoGuessr.

2. **Офіційна база післяматчевої аналітики GeoGuessr (`data/geoguessr_postmatch_clues.json`)**:
   - Спарсено через авторизовану сесію з реальних онлайн-дуелей та змагальних матчів.
   - **430 унікальних офіційних карток підказок** GeoGuessr для **52 країн** світу.
   - Містить локалізовані назви, опис, категорії (`nature`, `architecture`, `road`, `pole`, `bollards`, `license-plates`, `road-signs`), положення сонця, кути огляду та посилання на якісні фото-приклади.

3. **Локальний комп'ютерний зір (Pixel-Level Computer Vision)**:
   - Модуль [`engine/vision_extractor.py`](file:///home/yurka/projects/geoscript/engine/vision_extractor.py) аналізує реальні пікселі:
     - **Небо та положення сонця** (північна/південна півкуля, екваторіальні широти).
     - **Колір та тип дорожньої розмітки** (жовті лінії для Америки/ПАР/Японії vs білі для Європи).
     - **Тип покриття дороги** (асфальт vs ґрунтові дороги).
     - **Колір ґрунту** (детекція характерної червоної землі Бразилії, Австралії, Кенії).
     - **Індекс рослинності (ExG)** (джунглі vs пустеля vs помірні широти).
     - **Артефакти Google Car** (детекція червоної машини України/Бельгії з просторовим обмеженням капота).

4. **Інтелектуальний скрипт визначення локації (`geoguessr_locator.py`)**:
   - Миттєво аналізує будь-яке фото або панораму.
   - Видає:
     - 🥇 **Найбільш імовірну країну та регіон** з відсотком впевненості.
     - 🥈 **Альтернативні варіанти** з поясненнями.
     - 🏆 **Офіційні картки підказок GeoGuessr** із зображеннями.
     - 🔬 **Виявлені фізичні параметри пікселів** (розмітка, ґрунт, рослинність, сонце).
     - 🏛️ **Офіційний профіль GeoGuessr** (столиця, домен, валюта, сторона руху).
     - 💡 **Обґрунтування за базами Plonk It та GeoGuessr**.

5. **Інтерактивний веб-інтерфейс (`--web`)**:
   - Локальний сервер без зовнішніх залежностей (`http://localhost:8080`).
   - **Підтримка вставки скріншотів прямо з буферу обміну (`Ctrl + V`)** з миттєвим запуском аналізу.
   - Drag & drop файлів, введення URL та інтерактивні картки знань.

6. **Бенчмарк та перевірка на реальних матчах (`test_real_match.py`)**:
   - Завантажує реальні дуелі з історії гри, звіряє передбачення з точною позицією і рахує Top-1 та Top-3 точність.

## 🚀 Встановлення та запуск

Скрипт працює на стандартному Python 3.8+ з мінімальними вимогами (Pillow, NumPy).

### 1. Визначення локації за зображенням або підказками
```bash
# Аналіз локального скріншота / панорами:
python3 geoguessr_locator.py --image /path/to/screenshot.jpg

# Аналіз із зазначенням помічених ознак:
python3 geoguessr_locator.py --clues "orange roof tiles, red soil"

# Аналіз за посиланням на зображення:
python3 geoguessr_locator.py --url https://example.com/streetview.jpg
```

### 2. Запуск інтерактивного Веб-інтерфейсу
```bash
python3 geoguessr_locator.py --web
# Відкрийте у браузері: http://localhost:8080
# Вставляйте скріншоти за допомогою Ctrl + V безпосередньо у вікно браузера!
```

### 3. Запуск верифікації на реальних матчах GeoGuessr
```bash
# Перевірити скрипт на 10 останніх дуелях GeoGuessr:
python3 test_real_match.py 10
```

### 4. Робота з базою знань Plonk It та GeoGuessr через консоль
```bash
# Переглянути гайд та офіційні післяматчеві підказки для країни:
python3 geoguessr_locator.py --country BR
python3 geoguessr_locator.py --country UA

# Порівняти дві схожі країни (наприклад, Україна та РФ):
python3 geoguessr_locator.py --compare UA RU

# Знайти, де зустрічається певна мета:
python3 geoguessr_locator.py --search "bollard"
python3 geoguessr_locator.py --search "roof tiles"
```

### 5. Запуск юніт-тестів
```bash
python3 test_locator.py
```
